# 🌿 Island Landscape Website (SEO Upgrade)


A website optimization project for Island Landscape, a landscaping business focused on improving online visibility, trust, and local search performance.

## 🌐 Live Site
👉 https://islandlandscape.us/

## ✨ Project Overview
This project focused on enhancing an existing website with foundational SEO improvements, better content structure, and stronger user trust signals — without a full redesign.

## 🚀 Key Improvements
- Improved meta titles and descriptions for search visibility
- Added Open Graph tags for better social sharing
- Implemented structured data (JSON-LD) for local business SEO
- Optimized on-page content for readability and keyword variation
- Added service area content to target local searches
- Improved image alt text for accessibility and SEO
- Added canonical tags to prevent duplicate content issues
- Created sitemap.xml and robots.txt for indexing

## 📍 SEO Focus
Targeted local search visibility in:
- Seattle
- Shoreline
- Edmonds
- Kenmore
- Brier
- Lake Forest Park
- Lynnwood

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript
- JSON-LD (Schema.org structured data)

## 🎯 Purpose
The goal of this project was to strengthen Island Landscape’s online presence, improve search engine rankings, and help attract more local customers through organic traffic.

## 📈 Results (Ongoing)
- Improved SEO foundation for long-term ranking growth
- Increased keyword relevance across service areas
- Enhanced trust and professionalism of the site
